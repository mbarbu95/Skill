Cybersecurity Scenario-Based Practice Set

40 professional scenario-based questions for practical security analysis and decision-making.

Scenario 1 - Privileged Access Request

A database administrator requests temporary elevated access to troubleshoot a production issue. The request is urgent, but the ticket contains only a short description and no business owner approval.

What is the most appropriate next action?

Correct answer: Require documented approval and apply time-bound privileged access.
Explanation: Privileged access should be approved, limited in duration, and logged. Urgency does not remove the need for authorization and accountability.

Scenario 2 - Endpoint Alert Triage

An endpoint alert shows powershell.exe launched from winword.exe shortly after a user opened an attachment. The command includes encoded content and initiates an outbound HTTPS connection to an unfamiliar domain.

Which activity is most suspicious?

Correct answer: PowerShell launched by a Microsoft Office process with encoded content.
Explanation: Office spawning PowerShell with encoded content is a strong indicator of malicious macro or document-based execution. HTTPS alone is common and not sufficient by itself.

Scenario 3 - Data Loss Prevention Event

A finance user attempts to email a spreadsheet containing account numbers to a personal mailbox. The message is blocked and the user receives a policy notification.

Which control most likely generated this event?

Correct answer: DLP
Explanation: Data Loss Prevention tools inspect content and enforce policies to prevent sensitive data from leaving approved channels.

Scenario 4 - Wireless Guest Network

A company wants visitors to access the internet without being able to reach internal file shares, printers, or management interfaces.

Which design choice best supports this requirement?

Correct answer: Place guest clients on a segmented network with restricted routing.
Explanation: Guest wireless should be separated from internal resources using segmentation, routing restrictions, and appropriate firewall rules.

Scenario 5 - Certificate Warning Investigation

Users report certificate warnings when accessing a company portal. The browser shows that the certificate was issued to a different hostname and is not trusted by the client.

What is the most likely issue?

Correct answer: Certificate name/trust validation is failing.
Explanation: A hostname mismatch or untrusted issuer causes browser certificate warnings and may indicate misconfiguration or interception.

Scenario 6 - Backup Strategy Review

A ransomware incident encrypted several shared folders. Backups exist, but the latest backup is also encrypted because it was connected and writable during the incident.

Which improvement would most directly reduce this failure mode?

Correct answer: Maintain immutable or offline backup copies.
Explanation: Immutable or offline backups prevent attackers from modifying or encrypting the recovery copy during an incident.

Scenario 7 - Network Access Control

The security team wants to verify device compliance before allowing laptops onto the corporate network. Non-compliant devices should be placed into a restricted remediation network.

Which technology best fits the requirement?

Correct answer: NAC
Explanation: Network Access Control evaluates device identity and posture before permitting network access or placing devices in restricted segments.

Scenario 8 - Web Application Protection

A public web application receives suspicious requests containing SQL-like payloads in form fields. The development team cannot immediately patch the code.

Which compensating control is most appropriate?

Correct answer: Deploy or tune a WAF rule set for the application.
Explanation: A Web Application Firewall can inspect and block malicious web requests while the underlying application is being fixed.

Scenario 9 - Cloud Storage Exposure

A cloud storage audit finds that a folder containing internal project documents is accessible through a public link without authentication.

Which action should be prioritized?

Correct answer: Revoke public sharing and require authenticated access.
Explanation: Public anonymous links expose data. Access should be restricted to authenticated and authorized users.

Scenario 10 - SIEM Correlation Rule

An analyst wants to detect successful logins that occur shortly after multiple failures from the same source against the same account.

Which data is most important for the correlation?

Correct answer: Timestamp, account, source address, and authentication result.
Explanation: These fields allow correlation of failed and successful authentication events over time for the same account and source.

Scenario 11 - Least Privilege Review

A service account used by an application has domain administrator rights, although the application only needs read access to one database.

Which recommendation best follows the principle of least privilege?

Correct answer: Reduce the service account permissions to only the required database access.
Explanation: Least privilege requires granting only the access necessary to perform the function, reducing impact if the account is misused.

Scenario 12 - Vulnerability Prioritization

A vulnerability scan identifies three findings: a critical internet-facing remote code execution flaw, a medium internal software version issue, and a low informational banner disclosure.

Which finding should be prioritized first?

Correct answer: The critical internet-facing remote code execution flaw.
Explanation: Severity, exposure, and exploitability drive prioritization. Internet-facing RCE presents high risk and should be addressed first.

Scenario 13 - Incident Evidence Handling

An analyst collects a disk image from a potentially compromised system. The image may be used in a formal investigation.

Which practice is most important for preserving evidentiary integrity?

Correct answer: Maintain chain-of-custody documentation and verify hashes.
Explanation: Evidence integrity depends on documented handling and hash verification to show that data was not altered.

Scenario 14 - Remote Access Hardening

Administrators access internal systems remotely. Recent logs show repeated login attempts from unusual locations against administrative accounts.

Which combination provides the strongest improvement?

Correct answer: VPN with MFA and conditional access policies.
Explanation: Secure remote access should require encrypted access paths, strong authentication, and risk-based restrictions.

Scenario 15 - Malware Persistence

A host shows a suspicious executable launched after every reboot. The execution source is a scheduled task created under a user profile path.

What does this most likely indicate?

Correct answer: Persistence mechanism.
Explanation: Scheduled tasks are commonly abused to maintain execution after reboot or user logon.

Scenario 16 - Email Authentication

A domain owner wants to reduce spoofed email using DNS-published policies and sender validation mechanisms.

Which set of technologies is most relevant?

Correct answer: SPF, DKIM, and DMARC.
Explanation: SPF, DKIM, and DMARC help validate email sources, message integrity, and domain policy handling.

Scenario 17 - Secure Configuration Baseline

A company deploys new servers using default vendor settings. Several unnecessary services remain enabled, and default accounts are still present.

Which activity should be performed?

Correct answer: System hardening against an approved baseline.
Explanation: Hardening removes unnecessary services, changes defaults, and aligns systems with security baselines.

Scenario 18 - Zero Trust Access

A company wants application access decisions to consider user identity, device health, location, and session risk rather than trusting traffic based only on network location.

Which security model best aligns with this approach?

Correct answer: Zero Trust.
Explanation: Zero Trust continuously evaluates identity, context, and device posture instead of assuming trust based on network placement.

Scenario 19 - Container Image Security

A development team uses container images from public repositories. Security wants to reduce the chance of deploying images with known vulnerabilities or embedded secrets.

Which practice is most appropriate?

Correct answer: Scan container images before deployment and enforce trusted registries.
Explanation: Image scanning and trusted registries reduce exposure to vulnerable, tampered, or misconfigured container images.

Scenario 20 - Logging Coverage Gap

An investigation cannot determine which user changed a firewall rule because administrative actions were not captured centrally.

Which improvement addresses the gap?

Correct answer: Forward administrative audit logs to a centralized logging platform.
Explanation: Centralized audit logging improves accountability, investigation capability, and tamper resistance.

Scenario 21 - Key Management

A development team stores encryption keys directly in application source code. The repository is accessible to many users.

What is the best recommendation?

Correct answer: Move keys to a secure secrets management solution.
Explanation: Secrets should not be hardcoded. Dedicated secrets management provides access control, rotation, and auditing.

Scenario 22 - Business Continuity Exercise

A company wants to validate whether it can restore critical services after a major outage without interrupting production systems.

Which exercise is most appropriate?

Correct answer: Tabletop exercise.
Explanation: A tabletop exercise allows teams to walk through scenarios, roles, decisions, and gaps without directly disrupting production.

Scenario 23 - API Abuse Detection

An API endpoint receives thousands of requests per minute from a single client token. The requests are valid in format but exceed normal usage patterns.

Which control would most directly reduce abuse?

Correct answer: Rate limiting and token-based monitoring.
Explanation: Rate limiting and monitoring help control excessive or abusive API usage while preserving legitimate traffic.

Scenario 24 - Mobile Device Loss

An employee reports that a company-managed phone containing work email was lost in a taxi. The device is enrolled in mobile management.

Which action should be performed first?

Correct answer: Initiate remote lock or wipe according to policy.
Explanation: Managed lost devices should be locked or wiped quickly to reduce unauthorized access to corporate data.

Scenario 25 - Firewall Rule Review

A firewall rule allows inbound traffic from any source to a management interface on TCP port 22. Only administrators from a known jump host require access.

Which change best reduces risk?

Correct answer: Restrict access to the jump host source address.
Explanation: Management access should be limited to authorized sources and monitored. Changing ports without filtering does not meaningfully reduce risk.

Scenario 26 - Phishing Report Handling

A user reports a suspicious attachment before opening it. The message appears to have been delivered to several other employees.

Which response is most appropriate?

Correct answer: Search for and quarantine matching messages across mailboxes.
Explanation: Reported phishing should be investigated across the environment to identify and remove similar messages before users interact with them.

Scenario 27 - Secure Software Development

Developers frequently introduce authentication flaws that are discovered late in production testing. The organization wants earlier detection.

Which approach is most appropriate?

Correct answer: Integrate security testing into the development pipeline.
Explanation: Security testing in the development pipeline helps detect issues earlier and reduces remediation cost.

Scenario 28 - DNS Investigation

Multiple endpoints begin resolving randomly generated subdomains under the same unfamiliar parent domain. Shortly afterward, each endpoint connects to different external IP addresses.

What activity could this indicate?

Correct answer: Command-and-control using domain generation or fast-changing infrastructure.
Explanation: Randomized domains and changing infrastructure are commonly associated with malware command-and-control or evasion techniques.

Scenario 29 - Role-Based Access

A hospital wants nurses, doctors, and billing staff to receive permissions based on job function rather than individual one-off assignments.

Which access model is most suitable?

Correct answer: RBAC
Explanation: Role-Based Access Control assigns permissions to roles aligned with job responsibilities, simplifying administration and consistency.

Scenario 30 - Physical Security Tailgating

An employee holds a secure door open for an unknown person who is not wearing a badge. The person enters a restricted office area.

Which security issue is demonstrated?

Correct answer: Tailgating.
Explanation: Tailgating occurs when an unauthorized person follows an authorized person into a restricted area without proper authentication.

Scenario 31 - Encryption at Rest

A compliance requirement states that data stored on employee laptops must remain unreadable if the device is lost.

Which control satisfies this requirement most directly?

Correct answer: Full disk encryption.
Explanation: Full disk encryption protects stored data by making it unreadable without the appropriate key or authentication material.

Scenario 32 - Insider Risk Indicator

A user downloads a large number of documents from projects they do not normally access shortly before submitting a resignation notice.

What is the most appropriate security response?

Correct answer: Review the activity under insider risk and data handling procedures.
Explanation: Unusual access and bulk downloads may indicate data misuse. The response should follow approved investigation and privacy-aware procedures.

Scenario 33 - Secure Time Synchronization

Several servers show inconsistent timestamps, making it difficult to reconstruct the order of events during an investigation.

Which service should be standardized across systems?

Correct answer: NTP
Explanation: Network Time Protocol synchronizes system clocks, which is essential for accurate event correlation and investigations.

Scenario 34 - High Availability Requirement

A critical application must remain available if a single server fails. The business can tolerate minimal interruption but not a full-day outage.

Which design is most appropriate?

Correct answer: Redundant servers behind a load balancer.
Explanation: Redundancy and load balancing improve availability by allowing service continuity if one server fails.

Scenario 35 - Privacy Data Minimization

A marketing form collects passport numbers, home addresses, phone numbers, and employment history for a newsletter signup. The newsletter only requires an email address.

Which privacy principle is most relevant?

Correct answer: Data minimization.
Explanation: Data minimization requires collecting only the information necessary for the stated purpose.

Scenario 36 - Security Awareness Outcome

Employees frequently approve unexpected push notifications for sign-in attempts they did not initiate.

Which risk is most directly represented?

Correct answer: MFA fatigue or push bombing.
Explanation: Attackers may repeatedly trigger push prompts hoping users approve one. Users should deny unexpected prompts and report them.

Scenario 37 - Segmentation Validation

After a network redesign, the security team needs to confirm that workstations cannot directly access database management ports.

Which method best validates the control?

Correct answer: Perform controlled connectivity testing between segments.
Explanation: Segmentation should be validated through controlled testing, firewall log review, and documented expected paths.

Scenario 38 - Patch Management Exception

A critical system cannot be patched immediately because the vendor application breaks during testing. The vulnerability is actively exploited in the wild.

What should be done while remediation is planned?

Correct answer: Apply compensating controls and formally track the exception.
Explanation: When immediate patching is not possible, risk should be reduced with compensating controls and managed through an approved exception process.

Scenario 39 - Third-Party Risk

A vendor will process customer data on behalf of the company. The business owner wants to onboard the vendor quickly.

Which activity should occur before approval?

Correct answer: Assess the vendor’s security and data protection controls.
Explanation: Third-party risk management requires evaluating vendor controls, contractual obligations, and data handling practices before onboarding.

Scenario 40 - Alert False Positive Review

An IDS alert fires when a vulnerability scanner performs an approved internal scan. The activity matches an attack signature but occurred during an authorized maintenance window.

How should the analyst classify the alert?

Correct answer: True detection of benign authorized activity.
Explanation: The IDS correctly detected behavior matching a signature, but context shows it was authorized scanner activity rather than malicious exploitation.
