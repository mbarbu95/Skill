Scenario 1 – Security Control Classification

A mid-sized organization is reviewing its security program. The security manager asks you to classify several safeguards according to their primary control category. Select the most appropriate category for each safeguard.
SafeguardYour Selection
1. A documented procedure requiring manager approval before access is granted to financial applications
2. Badge-controlled doors protecting the server room
3. Endpoint protection software configured to block known malicious executables
4. Mandatory security awareness training for new employees
5. Security cameras installed in the data center corridor
Recommended answers:
1. Administrative
2. Physical
3. Technical
4. Administrative
5. Physical

Scenario 2 – Incident Response Prioritization

A workstation begins displaying a payment demand, and the user reports that several local files can no longer be opened. The system is currently connected to the corporate network and has mapped drives to departmental file shares.

Arrange the following actions into the most appropriate operational order.

Available actions: perform root-cause analysis; isolate the affected host; restore data from a verified clean backup; validate the type and scope of malicious activity; rebuild or clean the affected system; document findings and lessons learned.
Recommended order:
1. Isolate the affected host
2. Validate the type and scope of malicious activity
3. Perform root-cause analysis
4. Rebuild or clean the affected system
5. Restore data from a verified clean backup
6. Document findings and lessons learned

Scenario 3 – Authentication Event Review

During routine monitoring, an analyst identifies a sequence of authentication and file access events involving a user account assigned to the HR department. 
09:14:22 AUTH_FAILURE account=andrei source_ip=185.44.12.9 reason=invalid_password
09:14:25 AUTH_FAILURE account=andrei source_ip=185.44.12.9 reason=invalid_password
09:14:29 AUTH_FAILURE account=andrei source_ip=185.44.12.9 reason=invalid_password
09:14:33 AUTH_FAILURE account=andrei source_ip=185.44.12.9 reason=invalid_password
09:14:40 AUTH_SUCCESS account=andrei source_ip=185.44.12.9 mfa_result=not_challenged
09:16:02 OBJECT_ACCESS account=andrei object=HR_Salaries.xlsx action=download
Recommended answer:
1. A successful password guessing or brute-force attempt against a valid account.
2. Multiple failed authentications followed by a successful login from the same external IP, then access to a sensitive HR file.
3. Enforced multi-factor authentication, combined with lockout/risk-based access policies.

Scenario 4 – Suspicious Email Assessment

A user forwards the following message to the security team and asks whether it is safe to follow the instructions. 
From: IT Support <it-support@secure-login-help.com>
To: maria.popescu@company.ro
Subject: Account suspension warning

Dear user,

Your mailbox will be suspended today due to unusual activity.
Please verify your account immediately:

http://company-login-security.com/verify

Failure to complete this action will result in permanent account deletion.

IT Department

Select all observations that should be considered suspicious.

Recommended answers: A, C, D, E, F.
B alone is not sufficient; a legitimate technology team may use a similar display name. The concern comes from the domain, link, urgency, generic greeting, and pressure-based wording.

Scenario 5 – Endpoint and Network Event Analysis

A security analyst is reviewing correlated DNS, web, process, file access, and outbound network telemetry from a single endpoint. 
10:02 DNS_QUERY device=PC-044 query=invoice-checker-update.net
10:03 HTTP_GET device=PC-044 url=hxxp://invoice-checker-update.net/client_update.bin
10:04 PROCESS_START device=PC-044 image=client_update.bin parent=browser.exe
10:07 SMB_SESSION device=PC-044 target=FS-17 share=Finance
10:08 FILE_READ device=PC-044 path=\\FS-17\Finance\payments.xlsx
10:11 TLS_OUTBOUND device=PC-044 dst_ip=91.210.44.18 bytes_sent=48291023
Recommended answer:
1. PC-044
2. HTTP download from invoice-checker-update.net followed by execution of client_update.bin with browser.exe as the parent process.
3. TLS_OUTBOUND to 91.210.44.18 with 48,291,023 bytes sent.
4. The Finance share on FS-17, specifically the payments.xlsx file.

Scenario 9 – Cryptographic Concept Matching

A junior analyst is documenting cryptographic concepts used across several security services. Match each concept to the most accurate description.
ConceptYour Selection
1. Hashing
2. Symmetric encryption
3. Asymmetric encryption
4. Digital certificate
5. Salt
Recommended answers:
1. Hashing — Produces a fixed-length digest from input data
2. Symmetric encryption — Uses one shared secret for encryption and decryption
3. Asymmetric encryption — Uses separate but mathematically related keys
4. Digital certificate — Binds an identity to a public key
5. Salt — Adds unpredictable data before a password is processed
